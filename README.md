# Digital-Circuit
A Technology team that helps businesses, organizations, schools, sport clubs and government institutions improve their operations using technology

To run this project locally, clone this repository, install the dependencies using:

```bash
npm install
```

Navigate to the project folder then type this command to start the development server:

```bash
npm run dev
```

The demo of the front end is hosted at 
**https://digital-circuit.netlify.app**<br>
The admin section can also be viewed at 
**https://digital-circuit.netlify.app/admin**
